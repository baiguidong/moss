# 图片生成与编辑

使用内置 `image_gen`，无需打开 App。工具复用当前主会话的模型地址和 Key，图片模型可在设置中单独修改，默认 `gpt-image-2`。没有工具时检查主会话连接配置；不要索取聊天中的明文 Key，不改用临时 SDK 脚本。

## 工具参数

参数与 Codex ImagegenArgs 一致：

- `prompt`：要生成的内容或要进行的修改。
- `transparent_background`：是否要求透明背景，默认 false。
- `referenced_image_paths`：最多 5 张本地图片的绝对路径。
- `num_last_images_to_include`：使用当前会话最近 1～5 张图片。

两种参考方式互斥。不提供参考图时生成新图，提供参考图时使用这些图片进行编辑或组合。最近 N 张按会话图片顺序选择，可能包含新上传的图或截图；指代不明确时使用返回的文件路径。当前上下文不足时明确说明，不猜测图片。

## 工作流程

- 理解用途并整理提示词：主体、风格、构图、准确文字、必须保留与避免的内容。可参考 [提示词与检查](references/prompting.md)。不要擅自增加品牌、标语和装饰。
- 新建图片：`image_gen(prompt="…")`。连续修改上一张：`image_gen(prompt="…", num_last_images_to_include=1)`。指定多图：使用 `referenced_image_paths`。需要透明背景时明确传 `transparent_background=true`。
- 尺寸和质量交给服务自动选择，可在提示词中描述横竖构图。不要添加不存在的 out_path、aspect_ratio、mask、model、quality、n 参数，也不要承诺任意像素尺寸。
- 生成结果会作为图片回传模型，并直接展示在主会话。检查主体、文字、构图、透明背景与编辑不变量；需要修正时用返回的绝对文件路径继续编辑。
- 每次调用自动保存在当前工作区的 `generated_images/<会话>/<调用>.png`，修改生成新文件并保留原图。项目素材需要复制到目标位置并更新引用。
- 用户已经能看到图片，最终只需简短说明，不重复嵌入同一张图片，不添加整体“继续修改”入口。
- 不用生成图片伪造浏览器或应用运行截图。服务失败如实说明；主会话服务需要支持 Images 生成/编辑接口，工具不会切换账号或服务。

此技能使用 Moss 对 Codex 图片工具逻辑的 TypeScript 移植，不依赖 Codex 私有账号或运行时。
