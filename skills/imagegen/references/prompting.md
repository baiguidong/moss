# 提示词与检查

只保留与任务相关的项目：

- 用途：海报、网页素材、产品主图、角色立绘等。
- 主要要求：用户希望看到的具体内容。
- 输入图：哪张是修改目标，哪张是参考；工具未上传的图片不能声称已作为输入。
- 主体与环境：风格、构图、光线和材质。
- 图片文字：逐字引用，明确位置和层级；检查数字、中文和品牌拼写。
- 编辑不变量：只改背景，保留产品外形、边缘、颜色和相机角度等。

例：用户要求“把这张杯子的背景换成浅灰色”，提示词可以是“只将背景换成浅灰色摄影棚背景。保留杯子形状、颜色、图案、朝向与画面位置，匹配原有光照和自然接触阴影。不添加文字或其他物品。”

查看输出后再决定是否迭代。每轮重复必须保留的内容，只改变一个明确目标，减少偏离原图。

PNG 不等于透明：有 Pillow 等现成图像工具时可检查 alpha 通道是否存在且有小于 255 的像素，再目视确认边缘和背景。不具备检查工具时说明未验证透明性，不把棋盘格画面当透明背景。
