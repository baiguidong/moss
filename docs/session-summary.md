# 可选会话摘要

会话摘要默认关闭。开启设置中的「会话摘要」后，CLI、桌面和服务端主会话会注册 `SaveSessionSummary`，由当前模型判断是否值得记录，并直接提交摘要正文。保存工具不启动额外的摘要模型。

不再根据上下文 token、token 增长或工具调用次数提取摘要。工具说明明确跳过简单问候、常规工具活动和没有变化的内容；摘要内容对齐现有压缩提示词的保留重点：

- 用户请求、约束和纠正，以最新意图为准。
- 技术决策与原因、关键文件和修改、已验证的结果。
- 错误与修复、失败方案、尚未解决的问题。
- 已完成和待完成任务、当前工作、用户已授权的下一步。

仅记录当前可见对话中的事实，标明不确定和缺失信息。必要时保留原话、代码或精确标识，避免改变任务含义。工具说明使用精简要求，不复制压缩流程的长模板或分析标签。

## 与压缩的边界

「压缩时使用会话记忆」开关已移除。自动压缩、手动 `/compact` 和接口超限后的压缩均独立根据对话生成压缩结果，不读取或复用 `session-memory/summary.md`，失败时也不会回退到该文件。主动保存的摘要可以帮助回顾和检查需要保留的信息，但不能代表完整对话。

现有的回顾和技能整理功能仍可读取摘要文件。长期记忆提取和 Dream 的开关、触发规则保持独立。

## 存储与兼容

`SaveSessionSummary` 只接受一个 `summary` 字符串，最多 12,000 字符，拒绝空白内容。新内容整体替换当前会话的 `session-memory/summary.md`。路径由运行时确定，不接受模型指定路径。保存采用临时文件及原子替换；同一会话的并发写入被拒绝，取消或提交失败保留旧文件。子代理不能调用此工具覆盖主会话摘要。

未配置的用户默认关闭会话摘要，已显式开启的设置继续有效。旧 token、工具次数和摘要压缩配置字段仅为旧客户端及持久化数据兼容而保留，不再控制运行时行为；旧环境变量也不能重新启用摘要压缩。
