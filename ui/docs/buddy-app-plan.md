# Buddy 伴侣精灵：规划与首版实现

更新：2026-10-12。已实现 `moss.buddy@0.1.2`，依赖 Moss Host API 3.6。源码在相邻 `moss-apps/apps/buddy`；实现与验证记录见 [交付记录](buddy-app-delivery.md)。

## 产品定位

Buddy 是可以聊天的宠物，也是 Moss 的使用与配置助手。主流程是 **取名 → 选择形象 → 孵化 → 立即聊天**。日常聊天本身就是完整体验，用户需要帮助时再进入使用手册、设置和消息。

当前采用可独立安装、更新的官方 Moss App。形象、性格、聊天界面、内置助手规则和手册随 App 更新；模型、会话、权限、通知与全域配置由 Moss Host 提供。支持 App 页面、普通独立窗口和 Moss 窗口内的可拖动挂件。退出 Moss 后后台停止；完全脱离 Moss 的独立程序属于后续形态。

旧 Buddy 只有本地孵化、随机属性、ASCII 动画和拖动，没有真实聊天、配置或通知能力。本版替换活动入口，保留旧数据读取用于迁移。

## 用户体验

| 场景 | 首版行为 |
| --- | --- |
| 第一次打开 | 选择小苔团、机器人或光球，取名后孵化，不需要另装助手 |
| 孵化后聊天 | 固定见面问候明确标注；后续回复调用真实 Moss 模型，可停止、失败后重试 |
| 伙伴设置 | 修改姓名、性格、口吻、外形；保持同一身份、生日和对话 |
| 选择回应者 | 默认 Buddy 内置助手；高级设置可切换已有 Agent 或助手 |
| 选择工具 | 自带手册与配置工具，默认开放全部可用工具，可在 App 内切换为所选工具；仍受 Host 授权和所选 Agent 能力约束 |
| 使用手册 | 内置可搜索指南，覆盖模型、项目、hooks、记忆、助手、App、通知与远端连接 |
| Moss 配置 | 查询实际配置目录、范围、目标、当前值和来源，通过对话修改并撤销 |
| 消息 | 读取 Moss 通知中心，未读计数与已读状态同步，可关闭读取提醒 |
| 桌面陪伴 | 图形宠物挂件可拖动、展开与收起；显示开关也进入全域配置 |

三种形象采用 CSS 图形与动画，无 ASCII、无图片服务依赖；提供浅色/深色和减少动态效果支持。未来可替换为精细的图形素材或动画资源，而不改变会话和配置接口。

## App 内置助手与绑定

App 包含自己的助手规则和使用指南。每只宠物创建稳定身份，绑定一个专属的 Agent Channel conversation；连续聊天复用同一个 Moss 会话，App 私有目录保存宠物档案与聊天记录。

内置助手复用当前 Moss 模型，不要求用户先创建 Agent。性格与口吻影响表达，不改变权限。选择“已有助手”会加载其规则；选择“已有 Agent”走现有 Agent 调度与权限收敛。可用工具取用户选择与 Host/Agent 允许范围的交集。所选 Agent 不支持配置工具时，用户可切回内置助手。

修改形象、名字和口吻不会清空聊天；升级 App 保留独立数据目录。发送使用稳定请求 ID，Host 去重；重启时补查未完成轮次，避免重复回复。页面展示最近 200 条消息，完整记录继续保存在 App 数据文件中。

## 整个 Moss 的配置

这项能力覆盖桌面和 Agent，并统一其他已有配置领域。通用协议为 `moss.settings/v1`，由 Host 实现；Buddy 的全局工具让普通 Moss 对话也能使用同一入口，`update-config` 增加了发现与调用说明。

| 领域 | 作用范围与首版内容 | 保存与生效 |
| --- | --- | --- |
| `desktop` | 外观、模型默认值、推理参数、记忆、工具加载、运行时、连接地址、挂件等桌面设置 | 现有桌面保存与广播流程；外观立即生效，运行时默认值依现有会话刷新规则 |
| `agent` | Agent schema 中的用户默认、项目共享、项目个人覆盖，包括 hooks、权限、语言和清理规则等 | 实际运行时 schema 校验、来源解析与文件写入；支持删除当前层覆盖 |
| `session` | 本地及已连接远端会话的权限模式、推理强度 | 遵守只读、忙碌、模型支持档位与环境覆盖限制 |
| `apps` | 已安装 App 开关与声明的实例业务配置 | 调用 App Runtime 生命周期接口；不能借正在执行的 App 修改自身生命周期 |
| `mcp` | 已配置本地 MCP 服务的开关与连接/工具参数 | 现有 MCP 保存流程，空闲会话刷新，忙碌会话延后 |
| `assistants` | 已安装可编辑助手的规则 | 验证文件范围，内置助手只读；下次加载使用新规则 |
| `preferences` | 通用与终端偏好：终端主题、编辑模式、详细日志、压缩、检查点、通知方式等 | 现有全局偏好存储；终端界面变更通常下次启动生效 |

配置目录来自当前 Desktop 默认值、Agent schema 与各适配器，不能让模型凭空猜字段。App 可以新增适配器，Buddy 不需要内置每个配置文件的写法。

读写流程：

1. `catalog` 定位领域、范围和已知目标。
2. `read` 返回值、来源和 revision；密钥、环境变量与认证头等敏感容器脱敏。
3. `apply(preview=true)` 可预览变更；真正提交使用最新 revision、唯一 requestId 和具体路径。
4. Host 校验 schema、目标、策略与并发版本；Buddy 默认使用已授权的全部权限执行。切换为确认模式后，权限、hooks、执行命令等变更展示具体内容供用户确认。
5. 返回保存/应用状态和 receiptId。撤销检查该字段是否被后续修改，保护后来的值。

共享用户设置文件中的 Desktop 模型等字段交给桌面保存流程，Agent 专属字段由运行时保存；原始未知字段保留。混合不同存储语义的变更拆成独立回执。先落盘修改意图，再提交并记录结果；中断后重试会核对实际状态，不盲目重复写入。

敏感凭据通过原设置页面填写。远端连接参数与远端服务器设置分开：本版可管理本机连接默认值、已连接会话提供的参数；没有服务端管理 API 的远端项目/策略不会显示为可写本地设置。连接器安装、登录和授权仍走原连接器入口。

## 通知与手册

首版复用通知中心的消息与已读状态，不新增消息源，也不把模型输出伪装成系统通知。Moss 的现有任务或审批产生消息后，Buddy 可以展示。通知内容不自动转成 Agent 指令。

手册随 App 包发布，提供检索工具供内置助手回答用法。首版是结构化的基础指南；自动同步各版本完整文档、上下文帮助、深链接和失败诊断属于下一阶段。

## 迁移与边界

首次检测到可用的 Buddy App 时，把旧名字、性格、生日和用户标识迁移到 App 私有存储。重复迁移不覆盖已有宠物；旧 localStorage 保留，失败明确提示。旧挂件位置继续读取并按新窗口尺寸限制，旧可见性选择迁移到 `desktop.appWidgets.enabled`，旧改名重置生日的问题也已修正。

Host 只实现通用 Widget Host，通过 manifest 的 widgets/views 加载隔离 App 页面。停用或卸载 App 后移除挂件；隐藏挂件不会删除宠物数据。首版是 Moss 窗口内挂件，普通独立窗口也可聊天；透明置顶、系统桌面游走与点击穿透未列入首版实现。

## 后续优先级

1. 完善日常使用：通知跳转、来源过滤、免打扰、完整手册版本同步、历史分页与导出。
2. 扩充全域配置适配器：连接器专属业务字段、更多远端管理接口；统一来源与生效状态的可视化解释。
3. 打磨陪伴表现：更多图形资源、情绪与状态动画、语音输入/输出、专注场景。
4. 有实际需求时增加系统级透明悬浮窗；完全独立程序单独评估登录、运行时与后台服务成本。

迭代优先看聊天完成率、配置成功与撤销率、通知使用情况，以及模型成本；不以收集聊天正文为默认手段。

## 0.1.1 使用反馈调整

- 收起为 56 × 56 图标，去掉标题栏、名字和状态占位；点击展开、拖动移动。
- 打开后取消 App 外层卡片边框，避免与宿主窗口形成两层边框。导航高度 44px，宠物头部压缩为 40px 小头像、名字和伙伴设置入口；空闲状态不显示额外文案，陪伴天数移入伙伴设置。伙伴设置打开时替换聊天区域，快捷提示仅在首次聊天前展示。
- 移除 Moss 个性化中的 Buddy 专属分组和参数，伙伴偏好统一在 App 内管理。
- 默认全部执行权限及全部可用工具，可以切换确认模式或手选能力；Moss 其他会话的权限默认值不受影响。
- 人设按真实会话初始化，正常续聊只传用户原文；重启、失败重试和设定变化保持正确状态。
- Moss 设置以中文功能名称、用途、当前值和直接操作展示。终端配色、编辑快捷键、详细输出与桌面外观区分；存储领域不再作为用户必须选择的概念。
- 配置冲突仅在目标字段未变化时自动重试，保留后来的编辑；修复合法 App 工具名被权限校验器误拒绝的问题。

## 0.1.2 与 Moss 风格对齐

界面采用 Moss 的主题色与控件样式，背景跟随桌面外观；深浅色、系统主题、聊天字号、行高及消息间距同步。换形象只改变宠物，聊天界面不再随形象改变配色。移除聊天区的内层卡片，保留紧凑头部和透明小图标。
