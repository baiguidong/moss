# AI 自测执行与验收重构（2026-10-13）

> 最新 59 项原始结果与专项复核见 [逐项报告](../../output/self-test-redesign/all-59/REPORT.md)。下文前半部分保留 31 项阶段的历史测量，不作为当前完整范围的成绩。

原始 31 项运行耗时 1260.836 秒（21 分 1 秒），28 项通过、1 项失败、2 项阻塞。不能用“AI 测试本来就慢”解释这轮结果：重复上下文、图片传输、结果漏交和权限确认都有可以修复的问题。

## 已确认的原因

- 同一个控制会话持续积累历史、脚本和工具输出。104 次模型请求的上下文从 26,731 增至 305,972 token，累计输入 16,872,055 token（含缓存读取），其中未缓存输入 324,215、输出 63,505。
- 当前 GPT Messages 兼容网关把 `tool_result` 内的图片当作 base64 文本，模型没有看到真实截图。随机视觉标记实验中，原格式消耗 5,501 输入 token 且回答 `NO_IMAGE`；同一图片提升为用户图片块后为 295 token，并正确读出仅存在于图片中的随机标记。Core 在最终请求边界转换已识别的 GPT/o 系列模型，保留工具配对及来源；Claude 和未知模型不受影响。
- Apps 列表、记忆概览已执行页面操作，却遗漏有效 `record` 提交，因此报告阻塞。新版只补交一次，保留证据，不重放已完成操作；仍遗漏时继续明确标为阻塞。
- PDF 外层 DOM 看不到 Chromium 原生查看器内容，旧检测据此误判。新版读取原生查看器页码状态、截取实际内容，并真实点击放大，验证缩放值改变。
- `window.confirm` 的系统弹窗处理不稳定。权限选择器改为页面内模态确认，保留明确授权；取消和 Esc 不改变权限，只有确认启用才调用权限变更。
- 新测试目录曾重复安装文档转换等 Python MCP 依赖。新版复用按解释器与固定依赖哈希隔离的依赖缓存，业务数据仍留在独立测试目录。

## 新的执行流程

31 项默认用例先由 App 包内的固定 Playwright 脚本执行真实页面操作，存储逐项观察和截图，状态为待核对。每批最多 3 项创建全新的控制会话，只传本批预期、观察和证据路径。AI 读取截图后提交验收结论；脚本成功不直接等于测试通过。

脚本失败使用单独会话检查当前页面。错误记录包含具体对象和错误内容；不能以另一个正常区域推断报错已消失。缺少验证能力记为阻塞，实际不符合预期记为失败。控制会话只开放读取、本轮浏览器和自测结果工具。浏览器不回显已运行脚本，过长观察保存为文件，HTML 内嵌截图不再在每次状态更新时重新生成。

完整范围、使用方法和生命周期见 [self-test.md](self-test.md)。测试目标仍是发现可复现的问题，不能据此保证未测试功能或所有业务配置都没有缺陷。

- 权限确认专项在浅色、暗色、390 像素窗口验证初始取消焦点、取消、Esc、明确确认和视口适配；新实例的权限用例执行 3.241 秒，AI 验收 15.349 秒，取消后权限不变，确认后恢复原测试权限。
