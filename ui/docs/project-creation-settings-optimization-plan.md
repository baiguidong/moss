# 项目创建与设置优化方案

检查日期：2026-11-03。范围：项目创建会话、确认卡、手动创建、项目设置、项目会话继承，以及本机“木构科学小镇”的实际配置和创建草稿。已按本方案完成首版实现，并进行源码、持久化数据及桌面界面验证。

## 已核实的问题

| 项目 | 现状与原因 |
| --- | --- |
| 图标 | `ProjectIconPicker` 始终显示预览、全部图形、配色和恢复默认。生成后已经能换配色、换内置图标，但没有紧凑的收起状态。 |
| 指令内容 | 创建提示词及 `ProjectPlan.instructions` 没有区分长期规则、具体方案和首个任务。“木构科学小镇”实际保存了设计选型、十项交付要求、专家分工以及“优先形成 v0.1 总体方案”等阶段性内容。 |

| 指令高度 | 设置只指定 `min-h-[160px]`，基础 `Textarea` 带 `field-sizing-content`，长内容会继续撑高。 |

| 工作目录 | 预览和确认均通过 `stat` 要求路径已存在；底层创建只自动建立内部项目目录。“木构科学小镇”的原指定路径仍不存在，草稿目录为空，项目实际绑定内部默认目录。 |

## 目标交互

项目详情顶部采用一行：

```text
[← 返回项目] [项目图标] 木构科学小镇    [新会话] [添加资料] [整理项目] [⚙]
```

- 保留返回项目列表功能，将原独立的“项目 / 返回列表”合并到标题行、项目名称之前，默认显示“← 返回项目”。窄窗口可收为左箭头按钮，悬停及无障碍名称保持“返回项目”。返回时保留列表原有搜索、排序和滚动位置。
- 三个操作都放在项目名称后、设置前，在概览、会话、成果页均可使用。
- 设置按钮统一使用齿轮图标（现有 `Settings`），点击切换右侧设置栏；展开时高亮，不切换成折叠箭头。无常驻说明文字，无障碍名称使用“项目设置”。
- 删除会话页原“发起项目会话”操作行；概览移除原整理按钮；成果页移除原添加资料按钮。
- “添加资料”的文件选择、导入及进度状态上移至项目详情层，避免依赖成果页是否挂载；完成后刷新成果列表，取消文件选择不报错。
- 整理过程中直接把顶部按钮显示为“正在整理…”，阻止重复触发；必要的失败信息按需显示。
- 会话页仍保留搜索、筛选、排序和删除错误提示。移动按钮时必须把原操作行中的错误提示移出，避免一起删除。
- 顶部优先保留操作空间，长项目名截断；窄窗口使用紧凑按钮，操作不再新增独立行。

界面只保留操作、内容与必要状态，删除以下常驻说明，不换成另一段解释：

- “汇集会话登记的成果和添加的资料。移除列表项会保留原文件。”
- “会话继承项目默认配置，发送前可调整。”
- “会话空闲后自动提炼，定期整合项目记忆。手动整理会处理当前空闲的会话。”

设置里的同类解释性文案一并精简，字段名称已经能表达用途时不再加副标题或说明段落。安装、导入和整理的实时状态及真实错误按需出现。

设置栏展开后，删除顶部“项目配置”文字与旁边图标所在的整个标题行，直接显示配置内容；开关入口只保留在项目顶部齿轮按钮。项目图标编辑字段属于配置内容，仍保留紧凑的修改入口。

设置栏左边界可左右拖动，支持双击恢复默认宽度、键盘调整并记住宽度。复用主会话展示区的拖拽与窗口尺寸适配逻辑，设置栏宽度独立保存。内容纵向滚动，保存按钮固定在底部。

图标默认只显示当前图标与“修改”入口；点击才展开图形、颜色和恢复默认。保留生成图标作为可回选项，修改其他配置时不重置它。创建确认卡、手动创建及项目设置使用同一交互。

项目指令提供“编辑 / 预览”，使用同一份 Markdown 文本。建议固定高度约 180px，超出内部滚动；局部覆盖 `field-sizing-content`，避免影响其他输入框。创建确认卡同步采用有界高度的 Markdown 预览。

## 指令生成与继承

AI 生成的项目指令必须是 Markdown 原文，使用标题、列表、段落和真实换行；保存内容不额外包裹 Markdown 代码围栏。生成要求同时写入创建系统提示词和工具字段说明，不能只在界面展示时模拟换行。

生成内容只保留少量长期适用的协作规则和用户明确指定的基本约束，直接写入目标工作目录的 `AGENTS.md`。具体尺寸、材料、芯片、电源、模块、人员分工、采购阶段和版本交付清单进入后续项目会话或项目文档；“先形成 v0.1”等一次性要求不得写入项目指令。

生成策略放在创建系统提示词与工具字段说明中，不新增强制业务模板，不用关键词黑名单拒绝用户手工填写的指令。短指令即可，不为凑齐章节扩写限制。

“木构科学小镇”可采用如下长期指令示例：

```markdown
## 协作规则
- 默认使用中文，给出清晰、可执行的建议。
- 依据当前任务、用户最新确认和最新项目资料推进工作。
- 区分已确认事实、设计建议和待验证事项。
- 具体设计与阶段计划维护在项目文档中，随迭代更新。
```

生成并保存真实换行，贯通工具输入、草稿、项目记录、预览和会话注入链路。JSON 序列化遵循标准转义，解析后的指令字符串必须含真实换行，避免二次转义。编辑、Markdown 预览和会话注入共用同一份原文。“木构科学小镇”已有错误转义文本需要定向修复；不对所有用户文本全局替换 `\n`，以免破坏代码示例或本来需要的转义。

每个新建项目会话自动携带最新项目规则，首次任务也遵循同一继承链路。已有会话保留指令快照这一事实需要纳入修复范围：实现为每轮开始时自动同步，只更新指令，不重置会话其他设置；指令变化时重新载入会话运行时，不打断当前任务。

## 权限与目录

新项目默认权限统一为完全访问（`bypassPermissions`），用户明确选择时以其选择为准。统一创建提示词、工具 schema、草稿归一化、手动表单和底层创建的缺省值；新项目会话继承保存后的项目权限。既有项目明确保存的权限不做批量覆盖。

指定目录不存在时，保留原路径，预览标记“创建时自动建立”。提交创建后递归创建并绑定该路径；未指定路径时自动建立内部默认目录。路径被普通文件占用或无法写入时，显示具体错误并允许修改重试，不丢弃用户路径再改用默认位置。

实现上分开“检查路径可用性”和“准备实际目录”：预览阶段只检查，创建/保存阶段负责建立目录。会话创建之前目录必须可用；重复确认、安装失败后的重试和应用重启不应重复创建项目。设置和手动创建补充路径输入，支持填写尚不存在的目录。

“木构科学小镇”原路径为 `/Users/bgd/Projects/wood-science-town`。已在备份原配置后补建并设为默认工作目录；已有会话目录、成果文件和内部项目数据属于既有存储，不因改绑定而自动迁移或删除。

## 资源发现与安装

三个入口统一支持已安装、内置和市场资源，包括技能、专家、App。默认搜索覆盖全部来源，显示“已安装 / 待安装 / 安装中 / 需配置 / 失败”状态；自然语言推荐依据任务匹配度，不把已安装当成候选边界。

确认卡增加“添加资源”，可直接搜索并增补资源。项目设置中的 App 增加市场候选，技能/专家列表合并本地自定义资源，避免另一个方向的遗漏。

复用现有宿主端资源发现、精确 ID 解析、安装与恢复能力，形成创建和设置共用的准备流程，避免继续维护前端技能/专家同步和宿主创建两套不同规则。用户提交创建或保存后自动安装所选缺失资源，再持久化项目配置；安装失败保留选择，重试只补齐未完成部分。需要账号登录或配置的 App 显示对应入口，处理后可继续。

技能安装要统一市场 ID 与运行时 ID；当前前端同步会按名称等别名判断已安装，统一后以准确身份为主，避免同名误判。App 子服务选择沿用已有能力，市场未提供服务信息时在安装后补齐。

## 验收场景

- 返回入口与项目名称位于同一行、在名称前；点击回到项目列表并保留原列表状态，不再显示独立的“项目 / 返回列表”行。
- 从概览、会话、成果页均可在顶部新建会话、添加资料、整理项目；没有原有重复按钮或常驻说明行，三段指定说明均删除。
- 设置入口始终是齿轮图标，打开和收起正常，展开状态可辨识。
- 设置栏展开后不再显示“项目配置＋图标”标题行，直接进入配置内容。
- 从非成果页添加资料也能完成导入，取消选择及导入失败状态正确，成果列表及时刷新。
- 打开设置默认不展开图标；修改生成图标配色、切换图形、保存和重新打开后结果正确。
- 长指令不会撑高编辑区；编辑和预览都有内部滚动；设置栏可拖动，主内容仍可访问，保存按钮始终可达。
- 新建项目不指定权限时为完全访问，显式其他权限正常生效；新会话继承一致。
- 未存在的嵌套目录在提交创建后建立并绑定；已有目录可复用；失败和重试保留原路径。
- 在创建会话、确认卡、手动创建和设置中，均可选择未安装资源并完成安装；覆盖失败重试、同名资源、运行时 ID、App 配置和服务选择。
- 指令生成即为 Markdown 原文；经过保存、重新读取和会话注入后，标题、列表、空行及真实换行保持一致，界面不显示用来分行的字面量 `\n`。“木构科学小镇”的错误转义指令完成定向修复。
- v0.1 等阶段性要求留在后续项目会话，项目主页创建完成后不自动发起任务。
- 修改项目指令后，新会话携带新内容；旧会话从下一轮开始自动使用新规则。

实施时扩展现有创建服务、项目默认值、资源同步和 Electron 界面测试，补充真实宿主的临时目录创建与恢复检查；不使用真实项目作为自动化测试写入目标。
